# UnzipGit Android

## Описание

Android-приложение для распаковки ZIP-архивов в GitHub-репозиторий.
Интерфейс полностью на русском языке.

## Функции

- Распаковка локальных ZIP-файлов в GitHub
- Распаковка ZIP-архивов, уже находящихся в репозитории
- Поддержка загрузки в определенную папку (repo/folder)
- Проверка токена и валидация вводимых данных
- Обработка ошибок и повторные попытки при лимите API
- Возможность отмены операции
- Боковое меню навигации
- Выбор ветки репозитория (main, master и др.)
- Отображение статистики успешных/ошибочных файлов
- Пропуск системных файлов macOS
- Сохранение имени пользователя, репозитория, ветки и токена (кнопка «Забыть сохранённый токен»)
- Защита от выхода за пределы папки (пути с «..» нейтрализуются)
- Экран не гаснет во время распаковки, проверка подключения к интернету
- Повтор загрузки только неудачных файлов одной кнопкой
- Локальная библиотека JSZip (работает без CDN)
- Экран «Репозитории» (открывается при запуске): список, поиск, создание и удаление репозиториев
- Файловый менеджер репозитория: две панели, редактор с подсветкой, поиск, автокоммиты, скачивание файлов
- Экран «Токены и ключи»: сохранённые токены GitHub, SSH-ключи аккаунта, генератор ключей API
- Экран «Релизы»: создание релизов GitHub, загрузка файлов любого формата, управление релизами и их файлами

## Настройки компиляции

- Gradle: 8.5

- Kotlin: 1.9.24
- compileSdk: 34
- minSdk: 24
- targetSdk: 34
- Java: 17

## Сборка

1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Соберите APK: Build -> Build Bundle(s) / APK(s) -> Build APK(s)

## Использование

1. Введите имя пользователя GitHub
2. Введите репозиторий (можно с папкой: repo/folder)
3. Введите токен доступа с правом repo
4. Выберите ветку (опционально, по умолчанию main)
5. Выберите локальный ZIP или укажите **относительный** путь к архиву в репозитории (например `AIBuilder-Expo-v179.zip`).
   Не вставляйте полный URL github.com/... в поля «Ветка» и «Путь к архиву» — приложение v3.14 умеет разбирать URL, но правильнее указывать только имя ветки и относительный путь.
6. Нажмите "Распаковать в GitHub"
